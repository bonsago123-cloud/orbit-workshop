# 궤도 공작소 (Orbit Workshop)

설계한 모듈과 엔진 시간에 따라 자동 비행하는 2D 미니게임입니다. 외부 라이브러리, 계정, API 키가 필요하지 않습니다.

## 실행

Node.js가 있으면 `node preview-server.cjs`를 실행하고 `http://localhost:4173`을 엽니다. 혹은 dist 폴더를 정적 웹 서버로 제공하세요. 게임은 HTML, CSS, Canvas 2D, JavaScript로만 구성됩니다.

## 게임

- 9×7 격자에 1×1 조종석과 엔진, 1×1·2×1·2×2 동체를 조립합니다.
- 조종석 1개와 엔진 1개 이상, 상하좌우 연결이 필요합니다.
- 엔진마다 0~30초 사이 분사 시작·종료 시간과 4방향 추진을 설정합니다.
- 엔진 힘 / 총 질량으로 가속하고, 질량중심과 힘의 작용점에 따른 토크 / 관성모멘트로 회전합니다. 중력과 공기저항은 없습니다.
- 발사 후 조작 없음. 조종석 중심이 목표 반경에 들어오면 성공합니다.
- 회전한 모듈 사각형과 이동하는 행성 다각형 충돌, 영역 이탈, 30초 시간 초과는 실패입니다.
- 창 포커스 이탈과 비가시 상태에서 자동 정지합니다. 복귀 시 이어집니다.

## 검사

- `node verify-core.cjs`: 성공·충돌·영역 이탈·타임아웃·설계 검증과 20회 난이도 비교. `dist/difficulty-records.json` 생성.
- `/qa.html`: 공개 검사 도구. 버튼을 누르면 브라우저 DOM 입력, 두 크기의 iframe viewport, 저장, 포커스 이벤트, 효과, 실제 벽시계 10분 연속 실행을 검사합니다. 일반 플레이와 분리된 전용 저장 키를 사용합니다.
- `/verification.html`: 실행한 검사 결과, 범위와 한계, 제출 설명.
- `dist/browser-verification.txt`: 실제 브라우저 검사 출력.

20회 기록은 사람이 플레이한 기록이 아니라, 같은 물리 엔진을 호출한 자동 플레이입니다. 같은 10개 행성 seed(100~109)와 10개 엔진 입력을 두 묶음에서 반복하며 목표 반경 하나만 28에서 48로 변경했습니다.

## 파일

- dist/index.html: 게임 화면과 공개 규칙
- dist/style.css: 반응형 디자인
- dist/engine.js: 고정 시간 간격 물리와 승패 판정
- dist/game.js: 입력, 렌더링, 저장, 효과, 생명주기
- dist/qa.html, dist/qa.js: 브라우저 검사
- verify-core.cjs: 재현 가능한 물리·난이도 검사
- preview-server.cjs: 의존성 없는 개발용 정적 서버
- export-source.py: 공개 Git 저장소와 전체 커밋 소스 뷰 생성

공개 Git 소스는 읽기 전용 dumb HTTP 저장소입니다. 커밋 상세 화면에서 전체 ZIP 또는 Git bundle을 받을 수 있습니다. GitHub 계정이 필요하지 않습니다. 과제의 HTTPS 고정 커밋 URL은 생성된 커밋 상세 화면을 사용합니다.

## 저장

현재 비행 값은 메모리에만 유지합니다. 유효 설계, 누적 발사/성공, 최단 성공 시간, 효과 설정을 로컬에 보존합니다. 작성 중 연결이 끊어진 설계는 마지막 유효 설계를 덮어쓰지 않습니다. 빈/손상 저장은 기본값으로 복구합니다. 저장이 차단되면 메모리로 계속 플레이합니다.

## 공개 안전

분석/추적 서비스, 네트워크 API 호출, 키, 실제 인명, 연락처를 게임에 포함하지 않습니다. 저장은 방문자의 브라우저 안에서만 이뤄집니다. Git 작성자는 개인이 아닌 프로젝트명과 예약된 example.invalid 주소입니다.

## 회전 물리 업데이트

같은 방향의 일렬 엔진은 하나의 논리적 엔진으로 병합되며 셀 수 × 36kN을 출력합니다. 각 엔진 셀의 질량은 유지됩니다. 묶음은 첫 엔진의 분사 시간을 공유합니다. 클릭으로 묶음 방향을 회전하고 오른쪽 클릭으로 한 셀을 삭제합니다. L자 구조는 한 엔진이 아닙니다. 조종석 없이는 UI와 물리 함수 모두 발사를 거부합니다.

새 항로/다시 설계하기에서 새 행성 배치가 생성됩니다. 다각형 모습, 이동 벡터, 반사 경계 경로를 발사 전에 표시하고 비행 중에는 시뮬레이션 시간에만 연동합니다. 일반 게임은 무작위이며 `?qa=1&seed=100`은 검사 재현용입니다.

`physics-verification.json`은 최신 물리 검사, `browser-verification.txt`는 최신 브라우저 검사, `browser-verification-v1.txt`는 이전 버전의 10분 검사입니다. 최신 물리 버전의 10분 검사는 별도로 수행해야 합니다. 공개 검사 페이지에서 포함 여부를 선택할 수 있습니다.

## 중력·폭풍 업데이트
목표 반경은 현재24m(지름48m). 행성 질량별 중력과 시간·구역 한정 우주폭풍이 작용합니다. 발사 전 예보를 확인하세요. 현재 검사: `node verify-environment.cjs`. 기존 verify-core/qa 난이도 및 성공률 기록은 이전 버전 기준입니다.

재설계/Esc: 현재 맵과 설계 보존, 비행만 초기화. 초기화: 새 맵·기본 설계·기록 0. 중력 범위: 2.5 × sqrt(질량), 바깥 0. 폭풍 힘 기존 대비3배, 흐르는 방향 애니메이션. 브라우저 검사: qa-redesign.html.
