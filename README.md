# 궤도 공작소 (Orbit Workshop)

모듈과 엔진 시간을 설계하면 우주선이 자동으로 비행하는 2D 게임입니다. HTML, CSS, Canvas 2D, JavaScript만 사용하며 외부 라이브러리·계정·API 키가 필요하지 않습니다.

## 실행

`dist` 폴더를 정적 웹 서버로 제공하세요. Node.js가 있으면 `node preview-server.cjs`를 실행한 뒤 `http://localhost:4173`을 열 수 있습니다. Vercel에서는 Framework Preset을 `Other`, Output Directory를 `dist`로 설정합니다.

## 게임 규칙

- 9×7 격자에 조종석 1개, 동체 1개 이상, 엔진 1개 이상을 서로 연결해 배치해야 발사할 수 있습니다.
- 동체는 1×1·2×1·2×2 중 선택할 수 있습니다.
- 배치 화면 옆 십자키는 모든 모듈을 한 칸 함께 이동합니다. 하나라도 화면 밖으로 나가면 이동 전체가 취소됩니다.
- 엔진의 고유 번호는 새 엔진을 추가하거나 우주선을 이동해도 바뀌지 않습니다. 같은 방향으로 일렬 연결한 엔진은 하나의 묶음이 되어 시간과 방향을 공유하고 출력이 개수만큼 증가합니다.
- 엔진마다 0~30초 사이의 시작·종료 시간과 4방향 추진을 설정합니다. 엔진을 클릭하면 묶음 전체 방향이 90° 바뀝니다.
- 질량중심과 힘의 작용점에 따른 토크·관성모멘트로 이동과 회전을 계산합니다. 분사가 끝나도 회전 관성은 유지됩니다.
- 새 항로와 초기화 때 행성, 목표 지점, 우주폭풍이 무작위로 생성됩니다. 다시 설계와 Esc는 같은 맵과 우주선을 유지합니다.
- 행성 질량이 클수록 중력 범위가 넓습니다. 현재 범위는 `2.15 × √질량`이며 범위 밖에서는 중력이 0입니다.
- 폭풍은 예고된 시간과 원 안에서 화살표 방향으로 작용합니다. 중심에서 가장 강하고 가장자리에서 0이며, 합산 가속도는 4.8m/s²를 넘지 않습니다.
- 조종석 중심이 반경 24m인 목표 안에 들어가면 성공합니다. 행성 충돌, 비행 영역 이탈, 30초 초과는 실패입니다.

## 검사

- `node verify-core.cjs`: 필수 모듈, 엔진 병합, 회전, 무작위 목표, 충돌·시간 제한을 검사합니다.
- `node verify-environment.cjs`: 축소된 중력 범위, 폭풍 방향과 세기 상한, 50개 무작위 항로의 유한 물리값을 검사합니다.
- `/qa-redesign.html`: 십자키 이동·경계 차단, 엔진 번호 유지, 재설계·초기화·애니메이션을 브라우저에서 검사합니다.
- `/verification.html`: 최신 검사 범위와 결과를 보여줍니다.

`dist/verification-v2.html`과 `dist/difficulty-records.json`은 이전 목표 반경 비교 기록으로 보존한 역사 자료입니다.

## 주요 파일

- `dist/index.html`: 게임 화면과 규칙
- `dist/style.css`: 반응형 화면과 조작부
- `dist/engine.js`: 물리, 무작위 환경, 승패 판정
- `dist/game.js`: 입력, 렌더링, 저장, 효과
- `verify-core.cjs`, `verify-environment.cjs`: 자동 검사
- `export-source.py`: 배포본에 공개 소스 묶음을 생성

## 저장과 공개 안전

현재 비행 값은 메모리에만 유지합니다. 유효한 설계, 누적 발사·성공, 최단 성공 시간, 효과 설정은 방문자의 브라우저에 저장합니다. 분석·추적 서비스, 외부 통신, 개인정보, 비밀키를 포함하지 않습니다.

## 추가 수정
- 각 엔진 셀은 병합해도 자신의 고유 E번호를 표시하고, 스케줄에는 병합된 번호들을 함께 표시합니다.
- 목표는 오른쪽 x=900에서 y=60~540에 생성됩니다.
- 폭풍은 2.1~4.2m/s², 겹칠 때 합산 상한 4.8m/s²이며 화살표와 동일한 가속도 벡터를 사용합니다. 기존 속도와 중력이 함께 작용하므로 실제 진행 방향이 화살표와 즉시 같아지지는 않습니다.
- 중력 반경은 1.8×√질량, 부품 하나라도 경계를 넘을 전체 이동은 차단합니다.
- 화면 위쪽의 그림 규칙에서 필수 부품, 전체 이동, 병합과 시간, 환경 및 도착 조건을 안내합니다.

- 배치한 모듈을 마우스 또는 터치 드래그로 개별 이동합니다. 2×2 동체도 크기 그대로 이동하며, 중첩·격자 이탈 시 원위치를 유지합니다. 짧은 클릭은 기존 엔진 회전/삭제 동작을 유지합니다. 비행 중에는 이동할 수 없습니다.

## 폭풍 난이도
관측소 위 선택 메뉴: 쉬움 ×1, 보통 ×3(기본), 어려움 ×6, 극한 ×10. 난이도는 폭풍 가속도와 합산 상한에만 적용됩니다. 맵·설계·방향·시간은 유지되며 비행 중 변경할 수 없습니다. 선택은 브라우저에 저장됩니다. 극한의 중심 가속도는 21~42m/s², 합산 상한은 48m/s²입니다. 실제 폭풍을 받는 동안 우주선에 힘 방향 화살표와 가속도를 표시합니다. 초기화하면 보통으로 돌아옵니다.
