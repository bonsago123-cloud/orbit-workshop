# 궤도 공작소 (Orbit Workshop)

모듈과 엔진 시간을 설계하면 우주선이 자동으로 비행하는 2D 게임입니다. HTML, CSS, Canvas 2D, JavaScript만 사용하며 외부 라이브러리·계정·API 키가 필요하지 않습니다.

## 실행

`dist` 폴더를 정적 웹 서버로 제공하세요. Node.js가 있으면 `node preview-server.cjs`를 실행한 뒤 `http://localhost:4173`을 열 수 있습니다. Vercel에서는 Framework Preset을 `Other`, Output Directory를 `dist`로 설정합니다.

## 게임 규칙

- 9×7 격자에 조종석 1개, 동체 1개 이상, 엔진 1개 이상을 서로 연결해 배치해야 발사할 수 있습니다.
- 동체는 1×1·2×1·2×2 중 선택할 수 있습니다.
- 배치 화면 옆 십자키는 모든 모듈을 한 칸 함께 이동합니다. 하나라도 화면 밖으로 나가면 이동 전체가 취소됩니다.
- 배치한 모듈을 마우스 또는 터치 드래그로 개별 이동할 수 있습니다. 중첩·격자 이탈 시 원위치를 유지합니다.
- 엔진의 고유 번호는 새 엔진 추가·개별 이동·전체 이동 뒤에도 유지됩니다. 같은 방향으로 일렬 연결한 엔진은 한 묶음이 되어 시간과 방향을 공유하고 출력이 개수만큼 증가합니다.
- 엔진마다 0~30초 사이 시작·종료 시간과 4방향 추진을 설정합니다. 엔진 클릭은 묶음 전체 방향을 90° 회전시킵니다.
- 질량중심과 힘의 작용점에 따른 토크·관성모멘트로 이동과 회전을 계산합니다. 분사가 끝나도 회전 관성은 유지됩니다.
- 새 항로와 초기화 때 행성, 목표 지점, 우주폭풍이 무작위로 생성됩니다. 다시 설계와 Esc는 같은 맵과 우주선을 유지합니다.
- 행성 질량이 클수록 중력 범위가 넓습니다. 현재 범위는 `1.8 × √질량`이며 범위 밖에서는 중력이 0입니다.
- 폭풍은 예고된 시간과 원 안에서 화살표 방향으로 작용합니다. 중심에서 가장 강하고 가장자리에서 0입니다.
- 폭풍 난이도는 쉬움 ×1, 보통 ×3(기본), 어려움 ×6, 극한 ×10이며 난이도에 따라 폭풍 가속도와 합산 상한만 변합니다.
- 조종석 중심이 반경 24m인 목표 안에 들어가면 성공합니다. 행성 충돌, 비행 영역 이탈, 30초 초과는 실패입니다.

## 검사

- `node verify-core.cjs`: 필수 모듈, 엔진 병합, 회전, 무작위 목표, 충돌·시간 제한을 검사합니다.
- `node verify-environment.cjs`: 중력 범위, 폭풍 방향·상한, 상하 무작위 목표, 엔진 번호 유지, 개별 드래그, 난이도별 폭풍 변위를 검사합니다.
- `node verify-difficulty.cjs`: 현재 물리 버전에서 같은 seed 0~9와 같은 설계로 폭풍 난이도 하나만 보통 ×3에서 어려움 ×6으로 바꿔 10회씩 비교하고 `dist/difficulty-records-v3.json`을 생성합니다.
- `.github/workflows/submission-verification.yml`: Playwright Chromium에서 실제 벽시계 600초 장시간 브라우저 검사를 수행합니다.
- `dist/verification.html`: 현재 버전의 과제 검사 범위와 제출 설명을 보여줍니다.

`dist/verification-v2.html`과 기존 `dist/difficulty-records.json`은 이전 목표 반경 비교의 역사 자료이며 최신 난이도 선택 근거로 사용하지 않습니다.

## 최신 난이도 선택 기록

동일한 seed 0~9와 동일한 테스트 설계를 고정하고 폭풍 난이도 하나만 변경했습니다.

- 보통 ×3: 성공 2/10, 종료시간 중앙값 9.4833초, 범위 7.5083~24.4667초, 행성 충돌 7회·영역 이탈 1회
- 어려움 ×6: 성공 1/10, 종료시간 중앙값 9.4833초, 범위 7.5083~20.6333초, 행성 충돌 7회·영역 이탈 2회
- 최종 기본값: 보통 ×3. 어려움에서 성공 횟수가 줄고 영역 이탈 실패가 늘었기 때문입니다.

## 저장과 공개 안전

현재 비행 값은 메모리에만 유지합니다. 유효한 설계, 누적 발사·성공, 최단 성공 시간, 효과 설정, 폭풍 난이도는 방문자의 브라우저에 저장합니다. 빈 값과 손상값은 기본값으로 복구합니다. 분석·추적 서비스, 외부 통신, API 키·토큰·비밀번호를 사용하지 않습니다.

최종 10분 브라우저 검사 결과는 `dist/browser-verification-current.txt`에 기록되며 GitHub Actions가 `github-actions[bot]`의 noreply 주소로 자동 커밋합니다.
