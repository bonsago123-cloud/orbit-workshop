적용 순서
1) 압축을 풀고 위 파일들을 저장소 루트의 같은 경로에 덮어쓰거나 추가합니다.
2) main 브랜치에 커밋합니다.
3) GitHub Actions의 submission-verification 실행이 성공했는지 확인합니다.
4) 성공하면 워크플로가 dist/browser-verification-current.txt를 생성하고 github-actions[bot] noreply 계정으로 자동 커밋합니다.
5) 그 자동 커밋의 40자리 full SHA가 들어간 commit URL을 최종 소스 주소로 제출합니다.
6) Vercel이 그 최종 커밋을 배포한 뒤 공개 결과물 URL을 제출합니다.

워크플로가 push 권한 오류로 실패할 때만 확인
GitHub 저장소 Settings → Actions → General → Workflow permissions에서 GitHub Actions가 contents write를 사용할 수 있어야 합니다.
